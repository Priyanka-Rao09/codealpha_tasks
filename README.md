# CodeAlpha Python Programming Internship Tasks

This repository contains my tasks for the CodeAlpha Python Programming Internship.

## Projects

### 1. Hangman Game
Folder: `CodeAlpha_Hangman`
A Hangman game where the player guesses a word one letter at a time. Built with Python and Flask.

### 2. Basic Chatbot
Folder: `CodeAlpha_Chatbot`
A rule-based chatbot that replies to messages like "hello", "how are you" and "bye". Built with Python and Flask.

## How to Run
1. Open the project folder (e.g. `cd CodeAlpha_Hangman`)
2. Install requirements: `pip install -r requirements.txt`
3. Run the app: `python app.py`
